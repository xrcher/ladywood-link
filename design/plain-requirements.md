### Ladywood Link - Unsorted Plain Requirements
**Account and Security**
- The system must allow the user to either log in or create an account with a provided district sign-up code.
- The system should have distinct interfaces for residents and waste collection officers to facilitate the verification of recycling and reporting.
- The system must securely handle user data and only share sensitive details like location with authorized local authority.

**Dashboard/Key Features**
- The system must present an interactive dashboard with real-time data to provide updates on current green points level.
- Users must be able to receive points based on the weight of recycling, verified by collection officers via a QR code scan on the bin.
- The dashboard must present any sewage spillage warnings on the dashboard.
- The dashboard must provide a carbon footprint score, based on metrics tracked from the user’s household.
- The carbon footprint score must show methods to reduce CO2 levels in the household, depending on what is contributing the most.

**System**
- The system must award points for successful reports of fly-tipping or uncollected waste, once the issue has been resolved by city services.
- Users must be able to upload photos with a GPS tagged location of fly-tipping and uncollected waste, to target the 17k tonne backlog of waste from bin strikes.
- Users must receive green points for these reports once taken care of.
- Users must be able to log recycling waste on the app.
- Users must be able to receive points once a big man has verified.
- Users must be able to see the progress of any ongoing fly-tipping/uncollected waste reports that they have submitted.

**Environmental Monitoring**
- Sewage Alerts: The dashboard must integrate real-time data from "Top of the Poops" API to warn users of Combined Sewage Overflows in local areas.
- Flood Warnings: The system must provide urgent flood notifications, as 10% of Ladywood’s population is at risk from severe flooding.

**Water Poverty (Out of Scope (Could Have/Won't Have))**
- Usage Tracker: Users should be able to log water usage to monitor their spending against the disposable income threshold.
- Drought Awareness: During periods of low rainfall, the system should provide water conservation tips and alerts.
